Session Manager & User Audit

Track Every User Session, Activity & Operation — Full Security Audit for Your Odoo

See It In Action

Watch how Session Manager tracks every login, monitors user activity, and gives you full control.

Key Features

Session Tracking

Track all login sessions with IP address, browser, OS, device info, and GeoIP location detection. See who is logged in right now.

Activity Audit

Automatically track Create, Update, Delete operations with field-level change details. Know who did what and when.

Kill Sessions

Force-logout any active session with one click. Immediately invalidate suspicious sessions from the dashboard.

Login Notifications

Instant email notification when a new login is detected on any account. Stay informed about unauthorized access attempts.

Access Control

Two-level security: User role sees only own sessions and logs. Manager role has full access to all data across all users.

Auto Cleanup

Automatic cleanup of old sessions and audit logs via scheduled actions. Configurable retention period to keep your database clean.

How It Works

User Logs In

When any user logs in, the module automatically captures the session with IP, browser, OS, and device details.

Activities Tracked

Every create, update, and delete operation is logged automatically with the user, model, record, and timestamp.

Monitor Dashboard

View all active sessions, filter by user, date, or status. Analyze activity with pivot tables and graphs.

Take Action

Kill suspicious sessions instantly, configure auto-kill policies, and set up email alerts for new logins.

Tracks Every Operation Across All Models

Automatically monitors create, update, and delete actions on every model in your system.
